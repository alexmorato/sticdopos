📖 Formato esperado del JSON

Estructura general

El JSON debe ser un array de objetos con la siguiente estructura:

{ "question": "string con el texto de la pregunta", "options_good": ["string opcion correcta 1", ...], "options_bad": ["string opcion incorrecta 1", ...], "hint": "string con la pista o aclaración (opcional)" }

Campos requeridos

  • question: Texto de la pregunta
  • options_good: Array de respuestas correctas
  • options_bad: Array de respuestas incorrectas
  • hint: (Opcional) Pista o aclaración del concepto. Si hay una sola respuesta correcta, se usa como rationale; si hay varias, se conserva como pista de la pregunta

Ejemplo completo

[ { "question": "¿Qué modelo usa píxeles o celdas?", "options_good": ["Ráster"], "options_bad": ["Vectorial", "Topológico"], "hint": "Malla de celdas con valores (ej: orfotos)" }, { "question": "¿Cuáles son tipos de datos?", "options_good": ["Raster", "Vector"], "options_bad": ["Topológico"], "hint": "Dos modelos principales de representación" } ]
