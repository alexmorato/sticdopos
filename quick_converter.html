JSON Preguntas:

Formato esperado del JSON de entrada

El JSON debe ser un array de objetos con la siguiente estructura:

[
  {
    "question": "string con el texto de la pregunta",
    "options_good": ["string opcion correcta 1", ...],
    "options_bad": ["string opcion incorrecta 1", ...],
    "hint": ["string con la pista o aclaración del concepto relacionado con la pregunta"]
  },
  ...
]
  • question: Texto de la pregunta.
  • options_good: Array de respuestas correctas.
  • options_bad: Array de respuestas incorrectas.
  • hint: (opcional) Pista o aclaración del concepto relacionado con la pregunta.

Ejemplo:

[
  {
    "question": "¿Qué modelo usa píxeles o celdas?",
    "options_good": ["Ráster"],
    "options_bad": ["Vectorial", "Topológico", "Matricial"],
    "hint": "Malla de celdas con valores (ej: ortofotos)"
  }
]
